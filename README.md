# 128x128-face-generator

## 概要
M5AtomS3Rなどの128x128ピクセルディスプレイ向けに、画像ファイル（PNG / JPEG）をC++の1ビット配列データ（`uint8_t`）に変換するWebベースのジェネレーターツールです。

M5GFXの `drawBitmap` 関数と組み合わせて使用することを前提としており、生成されたコードをマイコンに組み込むことで、フルスクリーンのドット絵や表情アニメーションを簡単に実装できます。サーバー通信を行わず、すべてブラウザのローカル上で動作します。

## 特徴
* **簡単操作:** 画像を選択するだけで即座にC++コードを生成します。
* **リアルタイムプレビュー:** 変換後の1ビット（白黒）の状態を画面上で確認できます。
* **配列名カスタマイズ:** C++コードに出力される配列名（`FRAME_IDLE_A` など）をUI上で自由に変更可能です。
* **ワンクリックコピー:** 生成された長大な配列データをボタン一つでクリップボードにコピーできます。

## 使い方

### 1. ツールの起動
* `index.html` をGoogle ChromeやSafariなどのモダンブラウザで開きます。

### 2. コードの生成
* 右側の設定パネルにある **「配列名 (Array Name)」** に、出力したい変数の名前を入力します（例: `FRAME_SPEAK_E`）。
* **「画像ファイルを選択」** ボタンをクリックし、変換したい画像（推奨サイズ: 128x128px）を読み込みます。
* プレビューエリアに白黒化された画像が表示され、同時に下部のテキストエリアにC++コードが出力されます。
* **「コードをクリップボードにコピー」** をクリックしてデータを取得します。

### 3. M5Atomへの組み込み
* コピーしたコードを、PlatformIOやArduino IDEのプロジェクト内（例: `face_presets.h`）に貼り付けます。
* メインの描画ループ内で以下のように呼び出します。

```cpp
#include "face_presets.h"

// ... 

// 128x128pxの画像をドット色(dot_color)と背景色(bg)で描画する
g_face.drawBitmap(0, 0, FRAME_SPEAK_E, 128, 128, dot_color, bg);
```

## 画像の仕様・推奨設定
* **サイズ:** 128x128ピクセル（これ以外のサイズも自動で128x128にリサイズされます）
* **カラー:** 白黒の2階調画像として作成することを推奨します。
* **しきい値:** ツール内部で明るさの中間値（127）をしきい値として2値化を行っています。透過（アルファチャンネル）を持つピクセルも、半透明以下の場合は背景（黒）として処理されます。
